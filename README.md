## 📖 项目源流

**《伊萨卡手记》** 最初是一款融合了**叙事理论**与**游戏化机制**的桌面端日记应用，现在正沿着同一产品目标发展为 Web 应用。

我们试图回应一个古老而恒久的命题：**“我是谁？”**

> “知道我是谁，就是知道我站在何处。知道我是谁，就是知道我从哪里来，要到哪里去。”

在这个被碎片化信息裹挟的数字时代，我们常常迷失了那个存在的“坐标”。《伊萨卡手记》试图为你构建一个虚拟的“精神栖居地”。这不仅仅是一个支持 Markdown 的文本编辑器，更是一场为期 **21天** 的奥德赛——我们希望通过书写，帮助你**重构自我叙事**，在混乱的日常中重新确认自己的立足点，找到生活的节奏。

在这里，你不仅是探索世界、装饰房间的 **玩家**，也是记录生活、构建自我的 **作家**。

### 🛠️ 工具：所见即所得的交互

* **🪑 交互式家具**：
    * 房间里的家具不仅仅是装饰，更是实用的功能入口；点击房间台灯或走廊壁灯可以分别切换明暗并在当前设备保持状态。
* **📝 书桌（纸页与书写）**：
    * **纸页是基本单元**：每张纸页只属于“碎片、主题、书信、书籍、日记”中的一种分类，也可以暂时未分类。
    * **分类与标签分离**：左栏可以按分类或按标签浏览；“学术”“伊萨卡手记”等标签可以跨分类复用。
    * **继续生长**：主题、回信与书稿都会回到书桌成为可编辑纸页，书籍无需先建立主题。
* **🧷 白板（主题拼接）**：
    * 从碎片纸匣取出纸页，在空间画布上拖动、排列并保存关系；完成后可带回书桌继续写成主题纸页。
* **📫 信箱（收件与寄件）**：
    * 收件箱阅读旅程来信，回信会在书桌建立书信草稿；寄出后保存为独立、不可变的寄件快照。
* **📚 书架（珍藏与回顾）**：
    * 书架只陈列已经装订完成的书。书稿仍在书桌继续修改，已经上架的成书不会随之改变。
    * 所有内容可随账户数据一并导出，正文在浏览器内解密后生成明文归档。

### 🔮 未来：城市漫游与相遇

* **🏙️ 城市漫游 (2.0计划)**：
    * **视觉小说** 走出房间，去虚拟的城市街道散步。与不同的人物相遇，了解他们的故事。
* **🧩 叙事合成 (2.0计划)**：
    * **碎片收集**：留心收集散落在城市各处的神秘碎片。
    * **重组解谜**：将碎片重组，你可能会还原出前任房客尘封的故事，拼凑出这个世界背后的真相。
